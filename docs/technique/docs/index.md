# Spécification technique

Deux documents tiennent le socle. Le [DAT](dat.md) est l’architecture. Le [DCT](dct.md) est la conception. Chaque chapitre ci-dessous a un seul sujet. Un fait n’est écrit qu’une fois. Les autres pages renvoient.

Les demandes sont dans `docs/fonctionnel`. Le manuel décrit l’usage. Le PDF d’origine, `docs/specifications-gestion-ia.pdf`, est conservé. Il n’est plus la base de revue. Les états fait ou pas fait sont sur [Réalisations](realisations.md), le même tableau que Plus.

## Documents

- [DAT — architecture](dat.md)
- [DCT — conception](dct.md)

## Chapitres

- [Orchestration](orchestration.md) : ordre des règles avant le modèle.
- [Devis hybride](devis-hybride.md) : la demande `prépare un devis pour …`.
- [Recherche et modèles](recherche.md) : index, lecture des pièces, GPU, modèles.
- [Modélisation des données](modelisation.md) : tables, champs, liens, valeurs non stockées.
- [Écrans](ecrans.md) : routes et contrôles.
- [Écart](ecart.md) : demandes encore absentes du chemin livré.
- [Réalisations](realisations.md) : état fait ou pas fait.
- [Données et projet](donnees.md) : renvois vers le DCT et la modélisation.
